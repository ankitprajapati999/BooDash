# 💀 BOODASH 🕯️ (Halloween Horror Edition 🟦🎃)

> “A cursed flappy-style nightmare where physics behave… and sometimes don’t.”

---

## 👁️ What is BOODASH?

**BOODASH** is a Halloween-themed arcade survival game built in the browser using JavaScript Canvas.

You control a haunted bird drifting through a cold blue horror world filled with endless pipes that feel… slightly alive.

Fast gameplay. Simple rules. Weirdly addictive outcomes.

---

## 🧟 Core Experience

* 🐦 Tap / Space to survive
* 🌪️ Dodge endless cursed pipes
* 🧠 Gravity-based movement system
* 💥 One touch = instant game over
* 🏆 Score increases as you pass obstacles
* 🎃 Blue horror aesthetic with glitchy vibes

---
